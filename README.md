# Кальянная и Шахеды — мод для Unciv

Мод для [Unciv](https://github.com/yairm210/Unciv) — open-source ремейка Civilization V.
Весь мод на русском языке.

## Кальянная

Новое здание, доступное всем цивилизациям с самого начала игры.

- Стоит 60 производства, технологии не нужны.
- После постройки здание «освобождает место», и его можно сразу строить снова —
  в том же городе, сколько угодно раз.
- Каждая построенная кальянная **навсегда** даёт 1 **кальян**, а каждый кальян —
  **+1 к счастью**. Кальяны видны в верхней панели.
- Кальянами можно торговать в дипломатии, как железом или лошадьми: сделка идёт
  30 ходов, на это время счастье переходит к партнёру. ИИ покупает кальян за 100
  золота (если у него меньше двух) и продаёт по 50 за штуку.

## Шахеды

Новая цивилизация. Лидер — Саддам Хусейн, способность «Рой»:

- +25% производства боевых юнитов, −33% их содержания;
- трофеи: 50% стоимости каждого убитого вражеского боевого юнита золотом;
- +15% силы боевым юнитам рядом с другим своим боевым юнитом;
- каждый боевой юнит, погибший в бою, приносит 20 золота;
- **взрыв**: кто убьёт боевого юнита шахедов в ближнем бою (сам напал врукопашную
  или отбивался от рукопашной атаки шахеда), сам погибает. Выстрел стрелка,
  бомбардировка города или авиаудар безопасны.

Особый юнит **Шахед**: дрон за 25 производства, доступен с начала игры. Летит 4
клетки над любой местностью и водой, игнорирует зону контроля, бьёт с 2 клеток и
взрывается при атаке. С каждой эпохой (средневековье → атомная) сильнее на 50%.

Особое здание **Сборочный цех** (вместо мастерской): +3 производства вместо +2,
новые боевые юниты сразу получают 10 опыта.

## Установка на Android

1. Установите Unciv (Google Play, F-Droid или `Unciv-signed.apk` из
   [релизов](https://github.com/yairm210/Unciv/releases)).
2. Главное меню → **«Моды»** → **«Скачать мод по URL»**.
3. Вставьте ссылку `https://github.com/MASHINKA34/mod-Unciv` → **«Скачать»**.
4. Новая игра: **«Начать новую игру»** → **«Моды-расширения»** → отметьте мод.

Обновление: «Моды» → **«Обновить [мод]»** (или удалить и скачать заново).
Описания стандартных механик игра показывает на языке своих настроек — для
полностью русского текста выберите в Unciv «Настройки» → «Язык» → «Русский».

## Разработка

Проверка и упаковка картинок (нужны Python 3 и Java 21):

```
python tools/check_mod.py
```

Android не умеет упаковывать картинки, поэтому `game.atlas`, `game*.png` и
`Atlases.json` собираются этой командой и коммитятся в репозиторий.
